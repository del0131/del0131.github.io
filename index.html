About

Atiidot is a beauty mark tattoo studio in Gangnam, Seoul, South Korea. Every piece is done by hand-poke — no machine — so each beauty mark settles like a natural mole: soft, small, and personal. The studio is run by its owner-artist and works by reservation only.

아띠닷은 서울 강남의 핸드포크 미인점 타투 전문 스튜디오입니다. 기계가 아닌 손으로 직접 시술해, 원래 있던 점처럼 자연스러운 결과를 지향합니다. 예약제로 운영됩니다.
